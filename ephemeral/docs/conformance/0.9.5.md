## Colour matched, not eyeballed

The second sheet rendered greyer than the first. Measured in HSL:

| | hue | saturation |
|---|---|---|
| first sheet (VELVET, BISHOP, SPARROW) | 182–183 | **47–52** |
| second sheet, as generated | 183–185 | **24–36** |

Hue was already right; only saturation was off. Each tile was corrected per-tile toward 48
before encoding, factors 1.00 (DOLOROSA, already matched) to 2.01 (CARDINAL, the brightest
scene). Side by side the two sheets now read as one set.
